## Область действия / Scope

Эта редакция описывает обновление для **Minecraft 1.12.2 + HBM NTM Community
Edition 2.6.1.0**, сверенное с локальным кандидатом dev79 от 9 октября 2026 года.
Это экспериментальная линия. Документы не относятся к старым сборкам 1.7.10
или NTM Extended. Номер будущего публичного релиза выбирается отдельно;
«Modular Warfare Update» — название обновления, не новый номер версии.

This edition documents **Minecraft 1.12.2 + HBM NTM Community Edition 2.6.1.0**,
checked against the local dev79 candidate dated October 9, 2026. This is the
experimental branch, not the older 1.7.10 or NTM Extended builds. The public
release number is a separate maintainer decision; “Modular Warfare Update” is
an update title, not a new version number.

В ченджлоге собраны значимые игровые изменения всего обновления, а не только
последнего исправления. Старые журналы dev-сборок остаются в корневом
`CHANGELOG.md`. Если историческая инструкция противоречит этому руководству,
для указанной CE-сборки используйте это руководство.

The changelog covers the update as a whole, not just the last hotfix. Historical
development logs remain in the root `CHANGELOG.md`. Where older instructions
conflict, use this manual for the CE build specified above.

The project owner confirmed the necessary distribution permissions on
